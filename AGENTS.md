# AGENTS.md

This project is a test fixture. Keep it tiny.

- Run all checks with `./mvnw -B clean verify`. It runs the tests, JaCoCo and ktlint.
- Run only the tests with `./mvnw -B test`.
- Fix style problems with `./mvnw -B ktlint:format`.
- Do not add a dependency and do not change `pom.xml` or the wrapper.
- Write a unit test for each new method. New code must be covered.
